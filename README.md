# Calculadora de Imbuements para Tibia

Bem-vindo à Calculadora de Imbuements para Tibia! Este projeto é uma ferramenta útil para jogadores de Tibia que desejam otimizar seus imbuements de equipamentos.

## Sobre

Tibia é uma marca registrada da CipSoft GmbH. Esta calculadora foi desenvolvida como um software de uso público com o objetivo de ajudar os jogadores a calcular e planejar seus imbuements de forma eficiente. Foi feito com carinho por [wagner.fiorese](https://github.com/wagnerfiorese).

## Funcionalidades

- Cálculo para todos os tipos de imbuements.
- Cálculo fácil para saber o que é mais vantajoso para você: Gold Tokens ou Items.
- Planejamento e visualização das modificações aplicáveis.
- Interface amigável e fácil de usar.

## Como Usar

1. **Abra o Site**: Visualize o site em seu computador, celular ou tablet. O link é: https://wagnerfiorese.github.io/imbuements-calculator/
2. **Insira os Dados**: Forneça as informações necessárias sobre o equipamento e os imbuements desejados.
3. **Visualize os Resultados**: A calculadora mostrará o resultado com as informações detalhadas.
