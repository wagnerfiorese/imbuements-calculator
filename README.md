# Imbuements Calculator for Tibia

Welcome to the Imbuements Calculator for Tibia! This project is a useful tool for Tibia players who want to optimize their equipment.

## About

Tibia is a registered trademark of CipSoft GmbH. This calculator was developed as public use software with the aim of helping players calculate and plan their equipment efficiently. It was made with love by [wagner.fiorese](https://github.com/wagnerfiorese).

## Features

- Calculation for all types of imbuements.
- Easy calculation to know what is more advantageous for you: Gold Tokens or Items.
- Planning and visualization of applicable modifications.
- Friendly and easy to use interface.

## How to use

1. **Open the Website**: View the website on your computer, cell phone or tablet. The link is: https://wagnerfiorese.github.io/imbuements-calculator/
2. **Enter Data**: Provide the necessary information about the equipment and desired equipment.
3. **View the Results**: The calculator will show the result with the information provided.
